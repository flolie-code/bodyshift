# Assets

Bilder, Fonts und Icons für BodyShift.

## Struktur

- `fonts/` — Inter + Fraunces (siehe `docs/fonts.md` für Download-Anleitung)
- `images/` — App-Icon, Splash-Screen, Adaptive-Icon, Favicon
- `images/recipes/` — später: Rezept-Fotos

## App-Icons (fehlen noch)

Diese Dateien werden von `app.json` referenziert:

- `images/icon.png` — 1024×1024, kein Alpha, App-Icon
- `images/splash.png` — 1284×2778, Petrol-Hintergrund (#143A3F), Logo mittig
- `images/adaptive-icon.png` — 1024×1024, für Android Adaptive Icon (Vordergrund)
- `images/favicon.png` — 48×48, für Web-Version

Generierung: aus dem BodyShift-Logo per https://easyappicon.com oder Figma.
